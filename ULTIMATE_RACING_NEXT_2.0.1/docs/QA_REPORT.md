# ULTIMATE RACING 2.0.0 — 물리 및 레이스 밸런스 보고서

작성일: 2026-11-24  
기준 프로젝트: ULTIMATE RACING 1.9.0  
수정 전 백업: `ULTIMATE_RACING_NEXT_1.9.0_SOURCE_BACKUP_2.0.0.zip`  
주요 게임 파일: `public/game/index.html`

## A. 변경 사항

### 1) 가드레일 접근과 실제 충돌 분리

- 가드레일과 가까워졌다는 이유만으로 브레이크나 속도 손실을 적용하지 않는다.
- `resolveRoadEdgeContact()`는 도로 경계를 벗어난 요청 위치를 안전 범위 안으로 정렬한다. 이 위치 정렬만으로는 속도를 줄이지 않는다.
- 실제로 도로 바깥 방향으로 경계를 넘고, 횡방향 속도가 0.65m/s를 넘으며, 침범량이 0.012m를 초과할 때 충돌 이벤트를 만든다.
- 충돌 강도는 바깥 방향 속도와 경계 침범량을 사용해 계산한다. 속도 손실은 `1.2 + strength * 8.8` m/s, 재충돌 억제 시간은 0.48초다.
- 플레이어는 충돌 후 안쪽 방향 yaw 보정을 추가로 적용한다. AI는 동일한 충돌 함수의 속도 손실과 차체 방향 보정을 사용한다.
- AI도 경계 접촉 시 속도 손실과 안쪽 차선 복귀 목표를 받아, 도로 가장자리에서 계속 붙어 달리지 않도록 했다.
- 1시간 가상 검증 중 경계 허용오차 내에서 lane 값이 아주 조금 넘는 경우가 발견되어, 충돌/감속 없이 위치만 도로 안쪽으로 정렬하도록 수정했다.
- 가드레일 충돌 판정이나 도로 경계 제한을 비활성화하지 않았다.

단위 테스트의 서로 다른 충돌 강도에서 속도 손실은 약 1.62~8.19m/s로 관찰됐다. 이는 통제된 함수 입력의 결과이며 실제 3D 차량 접촉 계측값은 아니다.

### 2) 코너링 자동 감속 완화

- 원본에 `277`이라는 속도가 직접 하드코딩되어 있지는 않았다. 1.9.0에서는 이전의 0.72 코너 최고속도 배수 제거가 이미 적용된 상태였다.
- 2.0.0에서는 일반 코너링 중 매 프레임 속도에서 `tireScrub * dt`를 직접 빼는 처리를 제거했다.
- 횡가속도 요구량과 접지 한계의 이용률을 계산하고, 한계를 넘어설 때 가속 여유만 연속적으로 낮춘다.
- 해당 보조 함수에서 종방향 가속력 감소는 최대 3%로 제한했다. 이것은 속도를 강제로 주입하거나 브레이크를 적용하는 방식이 아니다.
- 대표적인 고속 코너 입력 106m/s에서 `longitudinalGrip=0.975568`로, 가속력 감소량은 약 2.44%였다. 최고 곡률 경계에서도 helper의 최저 grip은 0.97이다.

### 3) AI Easy 난이도

- Easy의 AI 속도/공격성 설정은 `speed=0.992`, `aggression=0.12`, `yieldDistance=34`로 조정했다.
- Easy AI가 플레이어보다 앞에 있고 같은 통로에 있으며 플레이어가 뒤에서 따라잡는 상황이면, 주변 AI가 덜 밀집한 방향으로 차선을 비켜준다.
- AI의 양보는 경로·차선 선택에 적용된다. 플레이어와 AI의 충돌 질량, 반발계수 및 충돌 resolver는 난이도에 따라 바뀌지 않는다.
- Normal/Hard/Expert의 경쟁 설정은 기존의 단계 순서를 유지했다.

### 4) AI Ghost Mode

- AI 그랑프리 시작 전 설정에 `NORMAL MODE`와 `GHOST MODE` 선택을 추가했다.
- 선택은 `localStorage`의 `ur_ai_vehicle_mode` 키에 저장된다. 초기화 함수보다 상태 변수가 먼저 선언되도록 순서를 수정해, 이전에 발생할 수 있던 temporal-dead-zone 초기화 오류도 방지했다.
- Ghost Mode는 AI 차체 재질의 복제본을 사용해 투명도 최대 0.43으로 표시한다. Normal Mode로 돌아오면 원본 재질과 render order를 복원한다.
- Ghost Mode에서는 플레이어-AI 및 AI-AI 차량 간 충돌/차량 회피 간섭을 끈다.
- AI 도로 경계/주행 코리더 처리와 레이스 진행·순위는 계속 실행된다.
- 보상 함수에는 Ghost Mode에 따른 감액 분기가 없으며, Normal/Ghost 보상 동등성을 테스트했다.

중요한 구조적 한계: 게임은 스플라인 기반 키네마틱 주행이며 산·바위·벽 모든 메시를 대상으로 하는 완전한 강체 물리 콜라이더 시스템은 아니다. 따라서 여기서 유지했다고 확인한 환경 처리는 도로 코리더/가드레일 경계 처리다. 모든 산악 메시와 벽의 실제 물리 충돌을 검증하거나 보장했다고 주장하지 않는다.

### 5) 드리프트 조작감

과도하게 빠른 회전과 너무 무거운 회전 사이의 중간 설정으로 조정했다.

| 파라미터 | 2.0.0 설정 |
|---|---:|
| 드리프트 yaw authority | 1.50 |
| 드리프트 회전 반응 시간 상수 | 0.31초 |
| 드리프트 lateral slip 계수 | 0.22 |
| 일반 조향 반응 시간 상수 | 0.24초 |
| 드리프트 각도 수렴 | 5.5 × dt 기반 지수 보간 |

이 값은 코드 설정 및 회귀 테스트로 확인했다. 실제 컨트롤러/키보드 입력으로 조향 시작 지연, 최대 yaw rate, 코너 탈출 편차를 실측한 것은 아니다.

### 6) 속도계 및 385 표시 오류

- 현재 HUD 값은 차량 현재 속도 변수 `speed`(m/s)를 `speedKmhText()`로 변환해 km/h로 표시한다.
- 0.05m/s 미만 또는 숫자가 아닌 값은 `000`으로 표시한다.
- 100m/s 입력은 360km/h, 정지 상태는 000으로 반환하는 테스트를 수행했다.
- 차량별 최고속도는 `performanceFor()`의 별도 성능 값이며, HUD 현재 속도에 최대속도를 대신 넣지 않는다.
- HUD 초기화, 레이스 시작, 메뉴 복귀 및 매 프레임 업데이트에 같은 formatter를 사용한다.

완주자 기본 순위 보상:

| 최종 순위 | 기본 코인 |

| 1위 | 180 |

## D. 5,000회 헤드리스 레이스 시뮬레이션

자동 QA에는 생산 차량 프로필·특수 능력과 2.0.0 난이도 속도 설정을 사용하는 5,000회 결정론적 시뮬레이션이 포함되어 있다.

- 총 레이스: 5,000회
- 실행 시간: 약 20.72초
- 참가 차량: 25대
- 코스 수: 2~20개 임의 선택
- 플레이어 전체 우승률 모델값: 80.14%
- 포디움 비율 모델값: 96.16%
- 난이도별 모델 우승률: Easy 100%, Normal 80.60%, Hard 76.45%, Expert 54.23%

이 모델은 실제 레이스를 5,000회 렌더링하거나 키보드로 플레이한 것이 아니다. 타임스텝 방식의 간소화된 키네마틱 모델이며, Easy AI의 실제 차선 양보, Ghost Mode, 도로/산악 메시 충돌, Three.js, 렌더링 및 수동 입력을 포함하지 않는다. Easy의 100% 승률 역시 실제 Easy 플레이 승률이 아니라 모델의 보조 주행/속도 가정에서 나온 결과다. 실제 밸런스 승인 자료로 사용하면 안 된다.

원본 수치는 `docs/simulation/race-simulation-5000.json` 및 `.csv`에 저장했다.

| 항목 | 결과 |

## F. 브라우저 및 성능 상태

Chromium headless smoke test를 두 방식으로 시도했으나 완료하지 못했다.

- WebGL 활성 실행은 컨테이너의 EGL/SwiftANGLE 초기화 오류를 냈다.
- GPU를 끈 DOM 덤프 실행도 제한 시간 내 DOM을 반환하지 못했다.
- 따라서 실제 3D scene, 버튼 클릭, Ghost Mode 외관, 실제 충돌 및 계기판을 브라우저에서 확인하지 못했다.
- `npm run build`도 실행했으나 `next: not found`로 중단됐다. 이 작업 컨테이너에는 `node_modules`가 없어 Next.js 정적 export와 EXE 빌드를 수행하지 못했다.

## G. 남은 구조적 한계 및 최종 평가

- 게임은 여전히 스플라인 기반 키네마틱 주행이다. 완전한 강체 물리 엔진과 모든 지형 메시의 독립 collider를 도입한 것은 아니다.
- Ghost Mode의 코드 경로는 차량 간 충돌만 생략하고 도로 경계/진행 계산은 유지한다. 단, 실제 3D 장면에서 외관과 전환이 올바른지는 브라우저 확인이 필요하다.
- Easy AI의 양보 동작은 소스/분기 테스트를 통과했으나 실제 밀집 차량 환경에서 사람 플레이어를 충분히 비켜주는지는 미검증이다.
- 드리프트 값은 중간 파라미터로 조정했으나, 실제 컨트롤 입력 측정은 미수행이다.
- 자동 QA와 가상 테스트는 통과했지만 브라우저 실행 및 성능 측정은 미완료다.

**최종 판정:** 2.0.0 소스 수정과 자동 회귀 테스트는 완료했다. 실제 3D 플레이·충돌·Ghost Mode 렌더링·FPS·Windows 실행까지 검증된 완성 릴리스라고 단정할 수는 없다. 배포 후 브라우저/Windows에서 실주행 테스트가 필요하다.
