## A. 변경 사항 및 수정 파일

### 주요 변경

1. **가드레일 자동 감속 제거** — 가드레일에 가까이 있다는 이유만으로 속도를 빼던 인위적 감속을 제거했다. 도로 경계 제한은 유지하고, 실제 도로 가장자리 접촉 때만 작은 충격 감속을 적용한다.
2. **플레이어 성능 유지/확인** — 1.7.0에서 이미 적용한 플레이어 속도 향상에 추가 전역 버프를 중복 적용하지 않았다. 기본 밸런스 차량의 실게임 설정값은 최고속도 106m/s, 가속 35.845m/s²다.
3. **GP 커리어 보상** — 10라운드 누적 보상, 난이도 배율, 코스 수 기반 완주 보너스, 연승 보너스, 10라운드 챔피언 보너스를 추가했다.
4. **중복/악용 방지** — 레이스 ID 기반 중복 정산 방지, 현지 날짜 기준 하루 최대 3회 유료 우승 보상, 패배 시 0코인, 저장 실패 롤백을 적용했다. 패배해도 커리어 라운드는 진행된다.
5. **차량 수집/상점** — 기존 무료 차량 10대는 소유 상태로 유지하고, 별도 가격을 가진 신규 차량 10대를 추가해 3D 모드의 차고를 총 20대로 구성했다.
6. **차량 특수 능력** — 출발 가속, 코너링, 드리프트 충전/종료, 직선 크루즈 터보, 고속 에어로, 니트로 효율, 고속 토크 등의 효과를 플레이어 및 AI 업데이트 경로에 연결했다.
7. **AI 속도 안정성 수정** — `makeAICar`에서 속도 계산에 사용하던 `rival.variation`이 생성 시 초기화되지 않은 문제를 발견했다. 유한한 범위(.975–1.023)의 결정론적 값을 초기화해 `NaN`이 AI 속도에 전파될 가능성을 제거했다.
8. **난이도 곡선 재조정** — 반복 시뮬레이션으로 Easy 1.005, Normal 1.0225, Hard 1.0245, Expert 1.030 배율을 선택했다. 각 단계의 AI 공격성 설정은 기존 구조를 유지했다.

### 가드레일

가드레일에 가까이 접근한 것만으로는 속도를 줄이지 않는다. 실제 도로 경계 접촉에는 차선/도로 경계 제한을 유지하며 충돌 반응으로 약 1.2m/s 감속을 적용한다. 자동 검사에서 레일 근처 직선 주행, 접근 중 가속, 코너링, 실제 접촉, 충돌 쿨다운, AI 경계 제한이 확인됐다. 이는 코드/상태 기반 검사이지 3D 콜라이더와 실제 컨트롤러로 수행한 브라우저 실주행은 아니다.

### 중요한 물리 엔진 한계

게임의 현재 주행은 **스플라인 기반 키네마틱 시스템**이며, 산·언덕·각 소품에 실제 삼각형 메시 콜라이더를 붙인 강체 물리 엔진이 아니다. 도로 경계 제약, 차량 차체 엔벌로프, 요각 투영, 스윕 기반 차량 접촉은 유지·보강했지만 산 메시를 포함한 모든 환경 메시의 실제 충돌을 보장하는 기능은 구현/실행 검증되지 않았다. 따라서 “어떤 상황에서도 모든 지형을 절대 관통하지 않는다”고 판정할 수 없다.

또한 이 환경에서는 Three.js CDN(jsDelivr 및 unpkg) DNS 확인에 실패했고 Chromium 브라우저 검증도 시간 초과됐다. 이에 따라 실제 3D 산/벽/바위 충돌, 25대 동시 주행의 렌더링 및 상점 실제 클릭 흐름은 미검증이다. 코드에 충돌을 끄는 방식의 수정은 하지 않았다.

## F. 5,000회 자동 레이스 시뮬레이션 및 경제 시스템

### 시뮬레이션 실행 조건

- 실제 실행 횟수: **5,000회**
- 실행 소요: **10.49초**
- 한 경기 참가자: 플레이어 1명 + AI 24대 = 25대
- 코스 수: 2–20개를 무작위 표본
- 시간 간격: 0.5초
- 결정론적 난수 시드: `0x81a7c0de`
- 플레이어 차량별: 250회 시작(난이도별 Easy 25, Normal 150, Hard 62, Expert 13)
- 완료 시간 평균: 495.53초(모델 시뮬레이션 값)
- 타임아웃 레이스: 0

이 테스트는 생산 프로젝트의 `CAR_DATA`, `CAR_PROFILES`, `BASE_PERFORMANCE`, 특수 능력 ID를 읽는 **실제 실행한 헤드리스 시간 단계형 운동학 모델**이다. 가속, 최고속도, 코너 속도, 드리프트 충전, 니트로, 차량 특수 능력을 계산한다. Three.js 렌더링, 실물 메시 접촉, 지형/가드레일 메시 충돌, 풀 AI 차선/교통 해결, 실제 키보드 사용자 조작은 재현하지 않는다. 플레이어는 보조 레이싱 라인과 직선 니트로 전략, 코너에서 일정 비율의 의도적 드리프트를 사용하는 모델이므로 수동 플레이 결과와 같지 않다.

플레이어 차량 선택 우승률은 차량별 250회 샘플이며 AI 조합은 매 경기 달라진다. DRIFT VIPER는 플레이어 선택 기준 70.8%, 필드 우승률 8.51%로 상대적으로 강한 신호가 있어 과도한 선택 집중 여부를 실제 게임 로그로 추가 확인할 필요가 있다. CORNER PHANTOM은 필드 우승률 1.47%로 상대적으로 낮다. 무료 차량도 필드 우승 2,248회로 경쟁에서 제외되지는 않았다.

### GP 보상 및 경제

**라운드 기본 보상**

| 라운드 | 기본 보상 | 라운드 | 기본 보상 |
|---:|---:|---:|---:|
| 1 | 100 | 6 | 600 |
| 2 | 150 | 7 | 800 |
| 3 | 225 | 8 | 1,050 |
| 4 | 300 | 9 | 1,400 |
| 5 | 450 | 10 | 2,000 |

추가 보상은 다음 계산을 사용한다.

- 난이도: Easy ×0.88, Normal ×1.00, Hard ×1.12, Expert ×1.25
- 투어 완주: `75 + (선택 코스 수 × 12)` 코인. 예를 들어 5개 코스면 135코인.
- 연승: 현재 연승 수 ×25코인, 최대 200코인.
- 10라운드 챔피언: 추가 1,500코인.
- 일일 지급: 현지 날짜 기준 최대 3회. 한도 초과 우승도 커리어는 진행하지만 코인은 지급하지 않는다.
- 패배: 우승 코인 0. 라운드 진행은 유지되고 연승은 0으로 초기화된다.
- 중복 레이스 ID는 다시 정산하지 않는다. 저장 실패 시 코인/보상 변경을 롤백한다.

5코스 Normal 1라운드 첫 우승 예시는 기본 100 + 투어 완주 135 + 연승 0 = **235코인**이다. 이 수치는 코드의 계산 규칙에 따른 예시이며 실제 플레이 시간 기준 구매 소요 시간은 측정하지 않았다.

구매 차량 가격은 2,500 / 4,500 / 6,500 / 9,000 / 13,000 / 18,000 / 25,000 / 35,000 / 50,000 / 75,000코인이다. 코인과 소유/장착 차량 상태는 `localStorage`의 `ur_economy_v1`에 schema 2로 저장한다. 기존 `ur_selected_car` 인덱스를 마이그레이션하고 기존 무료 10대를 항상 보유 목록에 포함한다. 브라우저 저장소를 사용자가 삭제하거나 다른 브라우저/기기로 이동할 경우 서버 동기화는 제공하지 않으며, 클라이언트 저장값은 변조 방지 서버 경제가 아니다.
